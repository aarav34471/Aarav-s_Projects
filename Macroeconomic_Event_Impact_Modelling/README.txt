Project: Predicting Short-Horizon S&P 500 Reactions to Macroeconomic Releases Using Finance-Domain NLP and Market Context

This archive contains the three notebooks used for the dissertation:

1. 01_data_processing_and_eda_retail_sales_clean_v3.ipynb
2. 02_finbert_embeddings_and_text_diagnostics.ipynb
3. 03_walk_forward_model_comparison.ipynb

Run order:
Run the notebooks in the order listed above.

Environment:
The notebooks were developed in Google Colab using Python.

If running in a different environment, file paths may need to be updated.

Data note:
The raw data is not included in this submission. Raw licensed Databento minute-level market data is not redistributed. However, the notebooks include the outputs used for the dissertation, including processed summaries, figures, model results, confusion matrices, classification reports, and evaluation diagnostics.

Dependencies:
Install the packages listed in requirements.txt.
